- 🎵 **TikTok** — videos (with audio extraction)

## 🚀 Installation

One command in Termux:

```bash
curl -fsSL https://raw.githubusercontent.com/v4zrashd/RASHDYTDownloaderTermuxx/main/install.sh | bash
```

The installer will:
1. Update packages & install dependencies
2. Install/upgrade the download engine
3. Install the `v4zyt` command
4. Set up storage access (downloads go to `~/storage/downloads/V4ZTube`)

## 🎯 Usage

Just run:

```bash
v4zyt
```

Then choose:

| Option | What it does |
|--------|--------------|
| `1` 🎬 | Download Video (MP4) — any supported site |
| `2` 🎵 | Download Audio only (MP3) |
| `3` 📃 | Download full Playlist (MP4) |
| `4` 🔄 | Update downloader engine |
| `0` ❌ | Exit |

Paste any video link when asked — that's it.

## 📋 Requirements

- **Termux** (from F-Droid — Play Store version is outdated)
- Android 7.0+
- Internet connection
- ~200MB free space

## 🗑️ Uninstall
