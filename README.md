## 🚀 Installation

One command in Termux:

```bash
curl -fsSL https://raw.githubusercontent.com/v4zrashd/RASHDYTDownloaderTermuxx/main/install.sh | bash
```

The installer will:
1. Update packages & install `python`, `ffmpeg`, `curl`
2. Install/upgrade `yt-dlp`
3. Install the `v4zyt` command
4. Set up storage access (downloads go to `~/storage/downloads/V4ZTube`)

## 🎯 Usage

Just run:

```bash
v4zyt
```

Then choose:

| Option | What it does |
|--------|--------------|
| `1` 🎬 | Download video (best quality MP4) |
| `2` 🎵 | Download audio only (MP3) |
| `3` 📃 | Download full playlist (MP4) |
| `4` 🔄 | Update yt-dlp to latest version |
| `0` ❌ | Exit |

Paste any YouTube video or playlist link when asked — that's it.

## 📋 Requirements

- **Termux** (from F-Droid — Play Store version is outdated)
- Android 7.0+
- Internet connection
- ~200MB free space (ffmpeg)

## 🗑️ Uninstall

```bash
curl -fsSL https://raw.githubusercontent.com/v4zrashd/RASHDYTDownloaderTermuxx/main/uninstall.sh | bash
```

Your downloaded files are kept.
